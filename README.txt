Art Grid Complete v1

طريقة الاستخدام:
1) شغّل التطبيق محليًا بالأمر npm run dev ثم افتح http://127.0.0.1:4173 في متصفح حديث.
2) اضغط مشروع جديد.
3) اختر صورة، اكتب اسم المشروع، ثم أنشئ المشروع.
4) استخدم الشريط السفلي لفتح الأدوات.

ملاحظات:
- الحفظ المحلي يعمل عبر IndexedDB في نفس المتصفح والجهاز.
- السحابة وتسجيل الدخول وAI تحتاج Backend/API خارجي، لذلك الواجهة موجودة لكن التشغيل الفعلي مؤجل.
- على iPhone قد يكون فتح ملفات HTML المحلية محدودًا حسب التطبيق؛ الأفضل استضافة المجلد على خدمة static hosting أو فتحه من كمبيوتر.
